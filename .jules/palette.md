## 2025-02-18 - Custom File Input Accessibility
**Learning:** Custom file input buttons are often visually represented by styling their parent `<label>`, while the actual `<input type="file" />` is hidden with `display: none` (`hidden` class). This removes the element from both the keyboard navigation tab sequence and the accessibility tree, making it entirely inaccessible. Replacing `hidden` with `sr-only` retains keyboard tab accessibility. Applying `focus-within:ring-2` focus styling to the parent label ensures there is a clear, visible focus indicator when the screen-reader-only file input is focused.
**Action:** When creating or auditing custom file upload triggers, never hide the underlying file input using `display: none` / `hidden`. Instead, hide it using `sr-only` and bubble focus indicators to the parent trigger via `focus-within`.
